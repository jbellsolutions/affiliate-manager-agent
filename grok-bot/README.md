# Funding Partnerships Director for Grok Bot

This is the sanitized funding-specific Grok Bot edition of Affiliate Manager.
It owns the affiliate revenue loop: program design, network segmentation,
partner sourcing and qualification, approved recruiting, onboarding,
activation, campaign support, attribution review, reporting, and reactivation.

It does not underwrite applicant files or submit funding applications. Qualified
funding opportunities hand off to the Funding Operations Director with source,
consent, partner attribution, owner, and next action intact.

The package contains no partner list, customer data, credentials, commission
schedule, private offer terms, browser sessions, or internal URLs.

## Package contents

- `PROFILE.md` — durable funding-partnership role and boundaries.
- `skills/` — four repeatable partner-program methods.
- `routines/` — three tenant-neutral routines, shipped paused.
- `manifest.json` — inventory, handoff contract, and approval rules.
- `INSTALL.md` — nontechnical installation and acceptance tests.
- `SHARE-CHECKLIST.md` — public-copy safety review.

Grok assigns one persistent computer per user, not per Bot. Every Bot in that
user account can share files, browser sessions, and logins. Each client must
install this package in the client's own Grok user account and connect only that
client's systems.
