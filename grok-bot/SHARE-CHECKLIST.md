# Share-link release checklist

- Profile, skills, routines, avatar, and description contain no partner list,
  customer data, credentials, private offer or commission terms, tracking links,
  internal URLs, browser sessions, or conversation history.
- `manifest.json` parses and every listed file exists.
- Every routine contains the `NO_CLIENT_SOURCE` isolation guard and is paused in
  the public template.
- Every mutable action has a narrow **Require Approval** rule.
- Local-computer execution remains disabled unless the client has a documented
  need.
- Synthetic sourcing, draft-only outreach, qualified-referral handoff, and
  no-client routine tests pass in a clean account.
- The shared preview is inspected while signed out.
- Each recipient installs a copy in that client's own Grok user account and
  connects only that client's systems.
- The copy is never represented as a lender, broker license, earnings promise,
  funding guarantee, or autonomous payout authority.
